Make the per-event runtime cheaper. Iterating, sorting and reading attributes of state values through their mutable proxies costs 25–75% less (a proxy is built for a list element without the class lookup and type-call dispatch, immutable values skip the tracking checks, and the `dataclasses.asdict` frame check only runs for proxied dataclasses). Deltas of proxied dataclass rows encode about a third faster. Persisting a state tree to redis now takes one pipeline round trip for all touched states instead of one write task per state, with one lock-expiry warning per tree instead of one per state; loading a pickled state skips a per-key filter, and the state-size check only runs on states that exceed the limit.
