The generated `package.json` no longer carries a framework-owned `postcss` override. The pinned `postcss` dev dependency already forces a single resolved copy for every transitive requirer, so the override was redundant — and because framework overrides are merged into `reflex.lock/package.json` and never removed from it, an unnecessary one cannot be retired by a later release. Projects that already installed 0.9.8 keep an inert `"postcss": "8.5.23"` override in `reflex.lock/package.json`; it matches the dev-dependency pin, so it changes nothing today and can be deleted by hand.
