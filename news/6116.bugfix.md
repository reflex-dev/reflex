Inbound socket events are decoded with the stdlib `json`, so client-supplied integers outside `-2**63..2**64-1` (snowflakes, large database ids) reach event handlers exactly instead of being rounded to floats. Reflex installs its socket codec on a subclass of the packet class, for the server it creates as well as for a custom `App.sio` that kept socket.io's default codec. Previously the server Reflex creates passed `json=` to `socketio.AsyncServer`, which assigns onto the shared `socketio.packet.Packet` and `engineio.packet.Packet` classes and so reconfigured every other socket.io server and client in the process. `update_package_json_overrides` leaves a `package.json` whose `overrides` is not an object untouched instead of replacing it.

Extra handler args sent alongside an upload (`__reflex_event_args`) and event data arriving as a raw string are decoded with the stdlib too, for the same reason.
