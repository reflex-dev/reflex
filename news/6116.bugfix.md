Inbound socket events are decoded with the stdlib `json`, so client-supplied integers beyond the signed 64-bit range (snowflakes, large database ids) reach event handlers exactly instead of being rounded to floats. A custom `App.sio` that kept socket.io's default codec gets Reflex's installed on a subclass of the packet class, rather than on the shared `socketio.packet.Packet` class, which would have reconfigured every other socket.io server and client in the process. `update_package_json_overrides` leaves a `package.json` whose `overrides` is not an object untouched instead of replacing it.
