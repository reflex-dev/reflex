Workflows page an operator when a run needs one. Set `REFLEX_WORKFLOW_ALERT_WEBHOOK` and every runtime — app, `reflex workflows worker`, or `reflex workflows serve` — posts one JSON alert to it when a run fails, times out, or needs attention, when a schedule drops occurrences, and when a delivery becomes a dead letter; `REFLEX_WORKFLOW_ALERT_KINDS` narrows the set. Each payload carries a `text` line, so a Slack-compatible incoming webhook accepts it unchanged. Alerts queue and post off the kernel's path with retries, so a slow or unreachable sink loses alerts, never runs. `reflex workflows doctor`, `GET /connections`, and the console's Connections page report whether a sink is configured, and dead letters now count as `deliveries_dead_lettered` on both the Prometheus and OpenTelemetry exporters.
