`REFLEX_MINIFY_VARS=1` shortens state var names on the wire, using the per-state ids that `reflex minify init`/`sync` now also write to a `vars` section of `minify.json`: a delta such as `{"a.b": {"items_rx_state_": []}}` becomes `{"a.b": {"c": []}}`. Sessions in Redis or on disk and `rx.Cookie`/`rx.LocalStorage`/`rx.SessionStorage` values keep their keys when minification is turned on or `minify.json` changes, and `minify.json` may now be loaded after Reflex was imported, so in-process `AppHarness` tests can run minified. See [minification](https://reflex.dev/docs/api-reference/minification/).
