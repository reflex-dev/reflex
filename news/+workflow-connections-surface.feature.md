Connections and secrets are one summary behind three surfaces: `reflex workflows doctor`, `GET /connections` on the standalone service (read scope), and the console's Connections page. Every dependency a deployment relies on is listed by name and presence — each webhook verifier's secret variable and whether it is set (a missing one is a problem: that webhook will refuse every delivery), unverified webhooks with their declared reason, the approval-link key, the API token or its scoped variants, and schedules that need a serving process. Values are never shown. The console badge counts problems, so "why did nothing happen" is answered before it is asked.
