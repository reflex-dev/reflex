A hand-edited `alembic/env.py` kept from an earlier release no longer stops `reflex run` when it fails, for example on the placeholder URL in `alembic.ini`: the startup check logs the error with the fix (move the file aside and run `reflex db init`), and the `reflex db` commands exit with that message instead of a traceback. Reflex also warns once that such an `env.py` is not the Reflex template, and replacing a stock `env.py` again keeps the earlier `env.old` as `env.old.1`.
