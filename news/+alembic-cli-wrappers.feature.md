`reflex db init` now writes a Reflex-aware alembic environment (`alembic.ini`, `alembic/env.py` and `alembic/script.py.mako`) that loads the app and reads `db_url` from rxconfig.py, and `reflex db migrate`, `makemigrations` and `status` are thin wrappers over `alembic upgrade head`, `alembic revision --autogenerate` and `alembic history --indicate-current`. The `alembic` command line works on the same environment, so `alembic downgrade -1` or `alembic upgrade --sql` need no extra setup. Apps initialized by an earlier release run `reflex db init` once to update `env.py`; existing revisions are kept.
