`reflex db init` now runs `alembic init` and installs an `alembic/env.py` that loads the app and reads `db_url` from rxconfig.py, and `reflex db migrate`, `makemigrations` and `status` are thin wrappers over `alembic upgrade head`, `alembic revision --autogenerate` and `alembic history --indicate-current`. The `alembic` command line works on the same environment, so `alembic downgrade -1` needs no extra setup. Apps initialized by an earlier release run `reflex db init` once to update `env.py`; the previous file is kept as `env.old` and existing revisions are kept.
