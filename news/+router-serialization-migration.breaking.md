`state.dict()` and state deltas no longer contain a `router` key; downstream consumers must use the `rx_router_session`, `rx_router_headers`, `rx_router_page`, `rx_router_url`, and `rx_router_route_id` entries instead. Session-token redaction must handle `rx_router_session.client_token` and `rx_router_session.session_id`, retaining support for `router.session` on older Reflex versions; see the [router serialization migration guide](https://reflex.dev/docs/utility-methods/router-attributes/#serialized-state-and-deltas).
