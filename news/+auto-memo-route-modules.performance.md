Auto-memoized components now compile into modules chosen by the pages that use them, not by the Python module that defined each page. A page imports them from its own module in `.web/utils/components/routes/`, which defines the memos only that page uses and re-exports the ones several pages share from a module in `.web/utils/components/shared/`, one per set of pages. A page no longer loads the memos of every other page registered from the same module, and pages from different modules no longer each carry a copy of the memos they share. `@rx.memo` components still compile into modules mirroring their source modules.
