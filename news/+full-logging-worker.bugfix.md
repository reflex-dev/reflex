With `REFLEX_ENABLE_FULL_LOGGING`, granian worker records reach the log file again: the worker's post-fork `logging.config.dictConfig` closes the fork-inherited file handler, which is now opened in append mode (truncating once up front) so it reopens instead of silently dropping every worker-side record. The legacy console file writer follows the reopened stream through a proxy, so its timestamped file copies no longer leak to stdout — which broke `--json` output purity — or crash on a closed stream.
