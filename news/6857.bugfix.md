Pin `REFLEX_ENV_MODE` to `dev` when a dev `AppHarness` initializes, mirroring `reflex run`. Previously an `AppHarnessProd` in the same process leaked `REFLEX_ENV_MODE=prod` via `export()`, so later dev harnesses compiled with route prerendering enabled and the dev server served prerendered page HTML; on pages with hydration hazards this failed hydration on every load, and events dispatched during the hydration-recovery window were dropped (the vite 8.2.0 `test_memo` full-suite failures).
