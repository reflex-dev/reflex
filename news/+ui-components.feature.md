New `rx.ui` component library: themable components built only on base HTML elements, small JS hooks, and Tailwind CSS classes -- no external component framework. Includes button, badge, card, alert, input, textarea, label, checkbox, switch, radio group, select, separator, skeleton, spinner, progress, avatar, dialog (native `<dialog>`), tabs, and accordion (native `<details>`). Components are themed through shadcn/ui-compatible CSS design tokens configurable from Python via `rx.ui.Theme` / `rx.plugins.UIComponentsPlugin`, from plain CSS, or per-component with Tailwind classes (merged with `tailwind-merge`); `unstyled=True` opts out of built-in styles.
