State vars changed with an in-place operator (`+=`, `*=`, `|=`, `&=`, `-=`, `^=`) now mark the field dirty, so the update reaches the frontend. This covers mutating a local alias of a state var, like `items = self.items; items += ["b"]`, which previously changed the backend value without sending it. The same operators on a state proxy outside a mutable async context now raise `ImmutableStateError` instead of silently mutating the state.
