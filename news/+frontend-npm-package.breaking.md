Frontend framework dependency versions are no longer declared in Python or pinned at the top level of the app's `package.json`: react, react-dom, react-router, socket.io-client, universal-cookie, and the build toolchain resolve through (or are copied from) the `@reflex-dev/reflex-base` package manifest, and legacy top-level entries are removed from persisted `reflex.lock/package.json` files on the next install. To pin a different version of any of these, use `overrides` in `reflex.lock/package.json`. The `REACT_VERSION` and `REACT_ROUTER_VERSION` environment variables no longer have any effect and warn when set (removal in 1.0). `react-helmet` is only installed when `rx.helmet` is used. Custom code importing `$/utils/state`-style specifiers keeps working through compile-time normalization and vite aliases, but should migrate to `@reflex-dev/reflex-base/*` imports; the files themselves no longer exist in `.web`.
