Background tasks now receive the state itself instead of a `StateProxy`. A state is writable while the running event holds its lock; outside of that, like in a background task, writes raise `ImmutableStateError` until the state is entered with `async with self`. `StateProxy`, `ReadOnlyStateProxy` and `ImmutableMutableProxy` are removed from `reflex.istate.proxy`, and `rx.get_state` returns the state, writable inside `async with` it.
