Calling a handler that a substate inherits from a parent state, as a method of `self` in a background task, now goes through the task's state proxy like any other handler. Outside `async with self` it raises `ImmutableStateError` (0.9 ran it on the parent state without the lock), and inside it `type(self)` is `StateProxy`, so use `self.__class__` to get the state class. See [Upgrading to Reflex 0.10](https://reflex.dev/docs/getting-started/upgrading-to-0-10/#calling-inherited-handlers-from-background-tasks).
