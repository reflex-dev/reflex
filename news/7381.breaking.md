Two state mixins that do not inherit from one another can no longer both declare a var of the same name: creating the state that combines them raises `MixinVarNameConflictError` instead of silently giving the two mixins one var. Declare the var on the state that combines them, which both mixins then use, rename it in one of the mixins, or declare it in a mixin both inherit from. A mixin may still declare without a default (`count: int`) a var that the parent state or another mixin declares, to type it for its own code.
