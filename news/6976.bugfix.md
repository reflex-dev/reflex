Switching package managers between runs (`REFLEX_USE_NPM` on or off) no longer persists the other manager's stale lockfile into `reflex.lock/`. Previously an npm install left `bun.lock` beside `package-lock.json` with a `package.json` that matched only one of them, and the next plain run failed `bun install --frozen-lockfile` until `reflex.lock` was deleted by hand.
