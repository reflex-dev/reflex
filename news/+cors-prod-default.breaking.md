In prod mode, when `deploy_url` is unset (now the default), the backend no longer sends CORS headers, so browsers cannot read cross-origin responses, and Socket.IO accepts same-origin connections only. With `deploy_url` set, that origin is allowed in addition to the backend's own. A split frontend and backend, a CDN-served frontend or a proxy that rewrites `Host` needs `REFLEX_DEPLOY_URL` set to the frontend's URL on the backend, for example `REFLEX_DEPLOY_URL=https://app.example.com reflex run --env prod --backend-only`. Previously any origin was allowed. Set `cors_allowed_origins` explicitly for other setups (`["*"]` restores the old behavior).
