While you develop, the type stub Reflex writes next to an imported JavaScript module types each function's arguments from its TypeScript annotations or JSDoc, so type checkers catch a wrong argument in Python, such as `celebrate("lots")` for `@param {number} count`. Production builds leave the source tree alone, and writing a stub does not reload the backend; see [Type Stubs](https://reflex.dev/docs/api-reference/browser-javascript/#type-stubs).
