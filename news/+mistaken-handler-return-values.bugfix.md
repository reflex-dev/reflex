Event handlers may return any value, which backend code that `await`s the handler receives. Returning `self.other_handler` (meant `type(self).other_handler`), an uncalled event creator such as `rx.redirect`, or a list holding one raises the "must only return/yield" `TypeError` again, as in 0.10, instead of silently doing nothing. Any other value returned by a handler that an event trigger such as `on_click` ran is dropped, and in dev mode a warning names the handler once.
