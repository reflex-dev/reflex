Fixed repeated full recompilation when the incremental compile cache encounters state defaults requiring Reflex serialization, such as Pydantic models or dates. Manifest write failures now produce visible warnings instead of silently disabling cache reuse. Cache invalidation now includes package initializers, missing file reads, and app entrypoints that also define pages. Incremental builds run plugin output hooks, preserve compile telemetry, and refresh stylesheets. The daemon records its own PID, releases backend compilation when it exits, preserves edits during watcher teardown, discovers new root-level sources, and reuses the parent's initial build. Explicit `app_module_import` configurations use full compilation because earlier import-time reads may be unavailable. Component-doc control IDs remain stable across partial builds, and Markdown-triggered Uvicorn reloads are limited to the experimental cache mode. The cache identity now includes the compile mode, so a production build never reuses development output, a backend worker consumes its `nocompile` marker even while the compile daemon owns the build, edits from a failed hot reload stay pending until a compile succeeds, and a full compile adopts the pages an incremental attempt already evaluated instead of evaluating them twice.
