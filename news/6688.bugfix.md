Fixed repeated full recompilation when the incremental compile cache encounters state defaults requiring Reflex serialization, such as Pydantic models or dates. Manifest write failures now produce visible warnings instead of silently disabling cache reuse. Cache invalidation now includes package initializers, missing file reads, and app entrypoints that also define pages. Incremental builds run plugin output hooks, preserve compile telemetry, and refresh stylesheets. The daemon records its own PID, releases backend compilation when it exits, preserves edits during watcher teardown, discovers new root-level sources, and reuses the parent's initial build. Explicit `app_module_import` configurations use full compilation because earlier import-time reads may be unavailable. Component-doc control IDs remain stable across partial builds, and Markdown-triggered Uvicorn reloads are limited to the experimental cache mode.
