State and event handler names can be shortened to ids from a checked-in `minify.json`; the frontend and backend must be built with the same file and settings. See [minification](https://reflex.dev/docs/api-reference/minification/).

```bash
reflex minify init
REFLEX_MINIFY_STATES=1 REFLEX_MINIFY_EVENTS=1 reflex run --env prod
```
