`reflex minify` compiles state and event handler names down to short ids. `reflex minify init` writes a checked-in `minify.json` holding a stable id for every state and event handler — `sync`, `validate`, `list` and `lookup` maintain and inspect it — and `REFLEX_MINIFY_STATES`/`REFLEX_MINIFY_EVENTS` switch the compiler and the event pipeline over to those ids:

```bash
reflex minify init
REFLEX_MINIFY_STATES=1 REFLEX_MINIFY_EVENTS=1 reflex run --env prod
```

The frontend bundle and the backend serving it must be built from the same `minify.json` and the same `REFLEX_MINIFY_*` settings; a page built against a different scheme is told so when it connects instead of silently failing to hydrate. See [minification](https://reflex.dev/docs/api-reference/minification/).
