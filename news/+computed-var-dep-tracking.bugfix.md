A cached computed var whose getter reached the state through `super()`, an alias of `self`, or a nested helper function now recomputes when the fields it reads change, instead of keeping the value it first computed for the whole session. `getattr(self, name)` and a getter that hands `self` to a function defined outside the state still cannot be read as a dependency list: such a var now recomputes on any change to its state, with a warning naming it and pointing at `deps=[...]` and `auto_deps=False` to make that narrow again.
