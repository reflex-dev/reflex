Pages and memo modules import `refs` from `$/utils/state` implicitly, so a custom component's `add_hooks` or a raw `Var` that reads `refs[...]` without declaring the import keeps working as on 0.10, including in the wrappers kept with `auto_memoize=False`. `refs` is internal and this implicit import exists only for compatibility; build ref expressions with `Var._as_ref()`, whose var data carries the import.
