Two state mixins that do not inherit from one another can no longer both declare a var of the same name: creating the state that combines them raises `MixinVarNameConflictError` instead of silently giving the two mixins one var. Rename the var in one of the mixins, or declare it in a mixin both inherit from. Mixins may still each declare without a default (`count: int`) a var that the state or its parent state declares, to type it for their own code.
