`rx.foreach` loop values now reach event handlers and memoized descendants. The item and index used to compile to the `.map` callback's parameters, which went out of scope as soon as anything referencing them was lifted into its own function -- an `on_submit` hoisted into a `useCallback` threw `ReferenceError: index is not defined` ([#3210](https://github.com/reflex-dev/reflex/issues/3210)). Each rendered item now publishes its value and index to its subtree, so a consumer reads them wherever the compiler places it.
