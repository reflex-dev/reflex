Added `reflex.workflow.otel.OpenTelemetryObserver`, which forwards workflow activity to OpenTelemetry as a span per attempt plus counters per transition. OpenTelemetry stays optional — Reflex does not install it, importing the module without it is fine, and constructing the observer says exactly what to install.

A span covers one attempt (claim to commit), not one run. A durable run can wait a day and cross machines, which is not something a span can represent; every span instead carries `workflow.run_id`, so "everything that happened to this run" is an attribute search across however many attempts and processes it took. The counters reuse `MetricsObserver`'s event-to-name mapping, so the two exporters cannot drift into reporting different numbers for the same deployment — a test asserts they agree.
