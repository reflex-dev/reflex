Methods of an optional string var (`str | None`) holding `None` no longer crash the page or the production prerender: the string acts as an empty string, so each method gives what it gives for `""`. For example, `lower` gives an empty string, `contains("a")` is false and `split(" ")` gives `[""]`. Before, the methods compiled to a native string method (`split` with a separator, `strip`, `lower`, `upper`, `contains`, ...) threw `Cannot read properties of null`, while `length`, indexing and slicing already read `None` as empty. Concatenation with `+` and the comparison operators are unchanged.
