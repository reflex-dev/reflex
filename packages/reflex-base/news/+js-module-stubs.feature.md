The type stub written next to a JavaScript module imported from Python types each function's arguments from TypeScript annotations or JSDoc, as the JSON value Python sends (`number` is `float`, `"a" | "b"` is `Literal["a", "b"]`, a `Map` or `HTMLElement` is `Any`). It declares the functions the compile finds the module exports, and one TypeScript cannot type takes any arguments; in development, `script-signatures.js` in `.web` reads the types with the typescript the app then installs.
