An event handler may return a value that is not an event, which backend code that `await`s the handler receives; returned events still chain and a returned coroutine still raises. Returning `self.other_handler` (meant `type(self).other_handler`), an uncalled event creator such as `rx.redirect`, or a list holding one raises the "must only return/yield" `TypeError` again, as in 0.10, instead of silently doing nothing; for an uncalled event creator the error asks "Did you mean to call it: rx.redirect(...)?". A non-event value returned by a handler that an event trigger such as `on_click` ran is dropped, and in dev mode a warning names the handler once.
