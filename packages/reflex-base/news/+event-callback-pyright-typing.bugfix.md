pyright on Python 3.11–3.13 types a bare `@rx.event` handler with its arguments again (`EventCallback[int]` instead of `EventCallback[*tuple[Unknown, ...]]`), and accepts generic annotations through the event namespace such as `rx.event.EventCallback[int]` or `rx.event.EventType[str]`. mypy keeps typing handlers as `EventCallback` and accepting `rx.event.EventSpec`, but as in 0.10.1 it rejects a subscripted generic from `rx.event`; import those from `reflex_base.event` instead.
