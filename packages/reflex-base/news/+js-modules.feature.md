Call the functions of JavaScript modules an app imports from Python without evaluating code in the browser: a call sends only the module's name, the function's name and JSON arguments, so apps whose Content Security Policy forbids `unsafe-eval` can use them. See [JavaScript Modules](https://reflex.dev/docs/api-reference/browser-javascript/#javascript-modules).

The generated `vite.config.js` now sets `resolve.preserveSymlinks: true`, so the bundler reads a symbolic link where it is instead of at its target. This applies to every link in `.web`, including a package that npm links into `.web/node_modules` for a `file:` entry in `frontend_packages`, or that `npm link` adds: it is bundled from that path, and the packages it imports are found from there, in its own `node_modules` and then in `.web/node_modules`.
