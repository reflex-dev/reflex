Add `SetVar` for `set[T]` and `frozenset[T]` state vars and literals, with `contains`, `length`, `union`, `intersection`, `difference`, `symmetric_difference`, `issubset`, `issuperset`, `isdisjoint` and `to_array` operations. The value still travels to the frontend as a JSON array; `rx.foreach` accepts a set var directly. `frozenset` values are now accepted by `LiteralVar.create`.
