React Compiler now optimizes generated components that use `id` refs, generated UUIDs, and memoized event handlers such as upload callbacks. The `react_compiler` option now installs the experimental `babel-plugin-react-compiler` release. Component `id` refs register through the new `useRegisteredRef` hook in `$/utils/state`. The `refs` object it fills is internal and not covered by compatibility guarantees. Enabling `react_compiler` now logs a warning that the option is experimental.
