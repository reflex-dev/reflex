Passing a backend var where a Var is built from a Python value, e.g. `rx.Var.create([State._secret])`, `rx.toast(State._secret)`, `rx.image(src=State._secret)`, `rx.box(id=State._secret)` or `rx.upload_files(on_upload_progress=State._secret)`, now raises `BackendVarFormatError` with the same explanation as `f"{State._secret}"`, instead of a generic `TypeError` or `ValueError`. Converting a backend var to text with `str()`, `%` or `!s` now raises it too, instead of putting the `Field` text in the page. This includes `print()` and logging of a class-level backend var such as `State._secret` in server code, which used to print the `Field` text; use `repr(State._secret)` there instead, as the error now says. Using a state var's field from `State.get_fields()` in the UI now says to use the var instead of claiming it has no frontend var.
