`orjson_dumps` raises `TypeError` for a value no serializer handles, matching the `json.dumps` calls it replaced, instead of silently writing `null` into a generated artifact. Strings that are not valid UTF-8 (such as a lone surrogate from a `surrogateescape` decode) are escaped rather than passed through raw, so the result can be written to a UTF-8 file or sent over the socket. A serializer registered under a union annotation (for example `MyEnum | None`) now disables orjson's native handling, as one registered under the bare type already did.
