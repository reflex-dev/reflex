The JSON helpers in `reflex_base.utils.format` use orjson when installed. `orjson_dumps` renders byte-identical output with or without it, handing payloads orjson cannot represent faithfully (non-finite floats, integers beyond 64 bits) to the stdlib. Socket payloads go through the new `orjson_dumps_socket`, which does the same so `NaN`/`Infinity` reach the frontend intact. `orjson_loads` parses with orjson, which rounds integers beyond 64 bits, so call sites that need exact values (such as `reflex.json`'s `project_hash`) read with the stdlib.
