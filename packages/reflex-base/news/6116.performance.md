The JSON helpers in `reflex_base.utils.format` use orjson when installed. Payloads orjson cannot represent faithfully (non-finite floats, integers beyond 64 bits) fall back to the stdlib, as do apps registering an `rx.serializer` for an `Enum` or `uuid.UUID`, which orjson would otherwise bypass. Socket payloads go through the new `orjson_dumps_socket` so `NaN`/`Infinity` reach the frontend intact. `orjson_loads` rounds integers beyond 64 bits, so call sites needing exact values (such as `reflex.json`'s `project_hash` and inbound socket events) read with the stdlib. Output is byte-identical with and without the extra, except for floats below 1e-4, where the two backends pick different representations (`0.00001` versus `1e-05`); artifact hashes are unaffected because they are computed with the stdlib.
