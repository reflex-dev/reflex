The JSON helpers in `reflex_base.utils.format` use orjson when installed, with byte-identical output either way. Payloads orjson cannot represent faithfully (non-finite floats, integers beyond 64 bits) fall back to the stdlib, as do apps registering an `rx.serializer` for an `Enum` or `uuid.UUID`, which orjson would otherwise bypass. Socket payloads go through the new `orjson_dumps_socket` so `NaN`/`Infinity` reach the frontend intact. `orjson_loads` rounds integers beyond 64 bits, so call sites needing exact values (such as `reflex.json`'s `project_hash`) read with the stdlib.
