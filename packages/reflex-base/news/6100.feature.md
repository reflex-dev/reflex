State and event handler names are resolved through a pluggable `NameResolver` on `RegistrationContext`, which is how the new `REFLEX_MINIFY_STATES`/`REFLEX_MINIFY_EVENTS` env vars make the compiler and the event pipeline emit minified names. A resolver now also reports a `digest()` of the names it rewrites, so a frontend and backend can detect that they were built against different schemes. See [minification](https://reflex.dev/docs/api-reference/minification/).
