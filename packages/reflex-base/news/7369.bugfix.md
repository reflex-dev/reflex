Server rendering no longer wraps each substate's context in its own `SubstateProvider` component, which doubled the render depth of every page. Apps with many substates could run the server renderer out of stack, failing every route with a 500 such as `SyntaxError: Invalid regular expression: /[^a-z-]/: Stack overflow`. The browser still gives each substate its own provider, so a delta only re-renders the contexts it changes.
