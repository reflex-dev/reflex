The frontend runtime (state/event plumbing, theming, helpers) is now a self-contained npm package at `reflex_base/frontend`, shipped in wheels as a deterministic tarball built by a stdlib-only build hook and unit-tested with vitest. Shipped modules no longer import per-app generated artifacts: the generated context module registers `env.json`/`reflex.json`/state config into the new `@reflex-dev/reflex-base/runtime` registry at import time, and `ColorModeContext` lives in `@reflex-dev/reflex-base/react-theme`. `reflex_base.utils.frontend_package` describes the bundled package (mode, path, manifest) and replaces the removed `PackageJson.DEPENDENCIES`/`DEV_DEPENDENCIES` constants; `constants.FrontendPackage` holds the module specifiers compiled output uses (`Dirs.STATE_PATH` and `ResetStylesheet` are removed).
