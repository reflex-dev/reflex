`deploy_url` now defaults to `None` instead of `http://localhost:3000` and is no longer derived from `frontend_port`. The new `Config.frontend_url` property returns `deploy_url` when set and `http://localhost:<frontend_port>` otherwise; the sitemap plugin builds absolute links from it. Code that reads `config.deploy_url` must now handle `None`: use `config.frontend_url` for the frontend's origin, or `config.api_url` when the backend serves the frontend from its own origin (single-port `--env prod`).
