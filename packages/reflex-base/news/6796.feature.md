Added four extension points (used by `reflex-i18n`, available to any package): `register_event_scope_provider` wraps each event's handler execution and delta resolution in an ambient context that is re-derived after the handler runs (e.g. the active locale), which plain middleware cannot do; `register_implicit_dependency` marks functions whose use inside a computed var getter implies a dependency on a var the getter never reads directly (e.g. a gettext helper reading the active locale from a contextvar); a plugin's `expand_routes` hook (`reflex_base.plugins.ExpandRoutesContext`) can register extra pages derived from the app's own, e.g. one route per locale; and a plugin's `eval_page_scope` hook returns a context each page is evaluated in, whichever plugin evaluates it, e.g. the locale a localized route is built in. The first two are no-ops with negligible cost when nothing is registered.
