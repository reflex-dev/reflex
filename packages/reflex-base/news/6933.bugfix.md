Loading `rxconfig.py` no longer swaps out `sys.path` for the duration of the import, which made concurrent first-time imports in other threads fail with `ModuleNotFoundError` (e.g. the lazy `granian` import while the backend starts). The cwd is now prepended and removed afterwards, a stale `rxconfig` module from a previously loaded project directory no longer fakes the existence check, and a module another thread imports while `rxconfig.py` loads is no longer mistaken for one of its dependencies and evicted.
