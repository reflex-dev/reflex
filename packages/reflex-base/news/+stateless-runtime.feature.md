Apps with `enable_state=False` run a local event loop that applies frontend events (`rx.redirect`, `rx.call_script`, `rx.call_function`, client state, focus, value and browser storage events) in the browser, in the order they were dispatched, and never connects. An event that needs the backend logs an error in the browser console instead of being dropped. `utils/state.js` now re-exports two modules: `utils/runtime.js`, with the helpers and events every app needs, and `utils/transport.js`, with the backend connection, which only the context module of an app with state calls into. Imports from `utils/state.js` keep working. In an app without state, `rx.call_script` code and callbacks see the exports of `utils/runtime.js`, `addEvents`, `navigate` and `params`.
