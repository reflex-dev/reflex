Under ty, a pydantic model field of a state, or a computed var that returns a model, now reads as `ObjectVar`, as it already did under pyright, `passthrough_event_spec` accepts a union type such as `int | None`, and a `hybrid_property` whose frontend var is a `@classmethod` reads as that var instead of `Unknown`. Generated `.pyi` stubs keep the defaults of fields in dataclass-like classes such as `PropsBase`, so type checkers no longer treat those fields as required.
