A column of a SQLAlchemy `DeclarativeBase` model whose column type gives no useful Python type, such as `JSON`, `JSONB` or `PickleType`, now has the type of its `Mapped[...]` annotation when read through a state var, so `data: Mapped[dict] = mapped_column(JSON)` supports `State.model.data["key"]`, and a `Mapped[list[str]]` JSON column supports `rx.foreach` and array operations, without `.to(dict)`. An annotation that refines the column's Python type, such as `Mapped[dict[str, int]]` over `dict`, is used too; otherwise the column type still decides.
