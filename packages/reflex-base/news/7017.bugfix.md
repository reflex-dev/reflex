A state var whose default comes from `dataclasses.field(...)` now works like `rx.field(...)`: the declared `default` or `default_factory` is used, instead of the app failing to compile with `TypeError: cannot pickle 'mappingproxy' object`.

Mutable defaults in unannotated dataclass fields are deep-copied for each instance, just like annotated fields, so changing one instance does not change another instance or the original default.
