`frontend_lazy_bundled_libraries` now defaults to `True`: `window.__reflex` holds React and the Reflex runtime, and gains each other registered library only once it has been loaded. Custom scripts that read a library from `window.__reflex` must first `await window.__reflex_load(["<library>"])`, or the app can set `frontend_lazy_bundled_libraries=False` to keep importing every registered library up front. Dynamic components and `rx.bundle_library` need no change.
