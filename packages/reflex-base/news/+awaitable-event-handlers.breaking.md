`@rx.event` now returns an `EventHandler` instead of the decorated function. A decorator stacked above `@rx.event` raises `TypeError` when the state class is created: apply other decorators below `@rx.event`. A module-level function decorated with `@rx.event` whose first parameter is not a state is now a stateless event handler, so calling it builds an event instead of running it; drop the decorator from plain helper functions.
