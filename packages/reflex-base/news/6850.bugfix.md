Compiler-generated memo wrappers whose body renders a tagged root now compile to `({children, ...rest})` and render the root with `mergeSlotProps(rest, {...own})`, a new `$/utils/state` helper that merges runtime-injected props following Radix `Slot` semantics: own props win, `on*` handlers compose, refs compose via the new `mergeRefs` helper, `className` strings concatenate, object-valued props deep-merge via `mergician` (now a base frontend dependency, pinned in `PackageJson.DEPENDENCIES`), and a prop the own side leaves valueless falls through to the injection. Merging never causes a render on its own: with nothing injected the own props object is returned by identity, and composed refs and handlers keep a stable identity while their inputs do, so a memoized root keeps its bailout and React does not detach and reattach refs on an unchanged node. Roots that render a `Fragment` — `rx.fragment` and components with an empty tag, such as `rx.upload` — stay opaque, since a `Fragment` accepts neither props nor refs.
