Compiler-generated memo wrappers whose body renders a tagged root now compile to `({children, ...rest})` and render the root with `mergeSlotProps(rest, {...own})`, a new `$/utils/state` helper that merges runtime-injected props following Radix `Slot` semantics: own props win, `on*` handlers compose, refs compose via the new `mergeRefs` helper with a render-stable identity, `className` strings concatenate, and object-valued props deep-merge via `mergician` (now a base frontend dependency, pinned in `PackageJson.DEPENDENCIES`).
