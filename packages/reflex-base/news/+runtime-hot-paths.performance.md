Cut the CPU cost of the backend event path. Reading a cached computed var no longer re-validates its cached value against the return type on every access (a 1000-element cached list read drops from ~1 ms to ~0.2 µs); a computed value of the wrong type is now logged once per computed value instead of once per read, and only a computed var with an `interval` stores a last-updated timestamp on the state, which shrinks pickled states. Scalar field reads and writes are about a third cheaper, and the per-event fixed cost of the event processor is lower: the event context is built once per enqueue, transaction ids come straight from `os.urandom`, and handler introspection happens once per handler. `EventHandler.is_background` and `EventHandler.supersedes` are read once per handler, so mark the function before the first read. `json_dumps` shares one JSON encoder per set of separators, and dataclasses serialize through a per-type serializer instead of `dataclasses.fields()` per instance, making small state deltas about 40% cheaper to encode.
