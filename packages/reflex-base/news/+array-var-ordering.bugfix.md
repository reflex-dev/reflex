List Var ordering comparisons (`<`, `<=`, `>`, `>=`) now follow Python list semantics instead of comparing comma-joined strings in the browser: items compare one by one, strings by code point, dates and datetimes by value, and equal dicts as equal. For example, `State.version >= [1, 9, 0]` is now true for `[1, 10, 0]`. An optional list Var whose value is `None` makes every ordering false instead of crashing the page.
