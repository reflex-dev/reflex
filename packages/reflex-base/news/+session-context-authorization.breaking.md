State access needs the browser session that owns the client token. `app.modify_state`, event enqueueing and uploads raise `SessionAuthorizationError` for a token that the session does not own; trusted server-side code passes `session_token=SessionToken.SYSTEM`. A tab that presents an unowned token gets a new token and fresh state. Set `REFLEX_SESSION_TOKEN_MODE=warn` to allow such access with a warning during a migration, or `off` to disable the check.
