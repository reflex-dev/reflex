`on_submit` handlers annotated `dict` (or not annotated) now receive a field name ending in `[]`, such as the `range[]` a two-thumb `rx.slider(name="range")` submits, as the list of its values (`["20", "80"]`) instead of its last value (`"80"`). Read `form_data["range[]"][-1]` for the last value, or annotate the form data as `rx.form.FormData`, whose `form_data["range[]"]` is the last value and `getlist("range[]")` every value.
