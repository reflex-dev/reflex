`reflex cloud deploy --gcp` now passes your Reflex access token to the Cloud Build image build, so apps using `reflex-enterprise` can complete `reflex export --frontend-only`. The token is staged as a Secret Manager version, referenced by resource name from the build config, mounted into `docker build` as a BuildKit secret (never reaching an image layer, `docker history`, or the build logs), and destroyed when the deploy finishes. Use `--token-secret` to point at a secret you manage yourself, or `--no-build-token` to deploy without a token.
