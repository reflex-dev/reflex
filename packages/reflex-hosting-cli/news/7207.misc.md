`reflex-hosting-cli` now talks to Reflex Build through `reflex-build-sdk` rather than its own HTTP layer, so every command shares the SDK's retries, timeouts and typed errors. While the SDK is pre-1.0 the requirement is capped to a single patch line (`>=0.0.3,<0.0.4`), so upgrade `reflex-hosting-cli` to move to a newer SDK rather than upgrading the SDK on its own.
