Every file the tool reads or writes — workflow templates, changelogs, news fragments, `pyproject.toml`, release notes, the pull request body and the GitHub Actions output and summary files — is now read and written as UTF-8 explicitly. Relying on the platform default meant `sync`, `init` and the release commands raised `UnicodeDecodeError`/`UnicodeEncodeError` on any system whose preferred encoding is not UTF-8 (notably Windows, where it is cp1252), and the templates themselves contain non-ASCII text.
