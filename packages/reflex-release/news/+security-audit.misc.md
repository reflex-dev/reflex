Hardened the generated release pipeline for use across repositories. The `pypi` environment gate now also fails when it can prove self-review is allowed, since required reviewers alone let the person who triggered a release approve their own upload. Branch prefixes are rejected when empty or when the main branch matches them — an empty prefix made `startswith` match every branch, silently turning "only these branches may publish" into "any branch may publish". `init` warns when the workflows end up invoking the tool unpinned, and its checklist now leads with the two settings that make the approval load-bearing. The README documents the trust boundaries, what the approval actually covers, and the ways an adopting repository can weaken it.
