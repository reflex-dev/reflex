`verify-dist` now checks each built artifact's distribution name as well as its version, and the checksum manifest of everything about to be uploaded is written into the build job's summary. Every package in a repository publishes through the same trusted-publishing identity and lockstep siblings share a version, so the name is what distinguishes them: nothing else stopped a misconfigured build from uploading one package under another's approval. The approver now sees the exact SHA-256 of every file before approving it.
