The `changelog-check` pull-request guard now also rejects news fragments the branch adds under a name that carries no pull request number. A towncrier orphan fragment (`+name.type.md`) is a placeholder for before that number is known, and one that survives to `main` renders a changelog entry with no link back to the change it describes — as does any other non-numeric reference, which towncrier turns into a broken issue link. Fragments already on the base branch are left alone, a rename to `<pr-number>.<type>.md` clears the failure, and the `skip-changelog` label still waives the whole check.
