Added `allow-self-review` to `[tool.reflex-release]`, defaulting to `true`. The `pypi` environment's reviewer list decides who can release, and by default one of those reviewers can carry a release through end to end — the right posture when that list is already a small trusted group. Setting it to `false` asks for a second person: the publish job then fails unless it can prove the environment prevents self-review — an unreported setting is treated the same as a permitted one, since strict mode is opt-in and the two are indistinguishable from the outside. Both postures still require an explicit, attributed approval before anything is uploaded.
