Added `allow-self-review` to `[tool.reflex-release]`, defaulting to `true`. The `pypi` environment's reviewer list decides who can release, and by default one of those reviewers can carry a release through end to end — the right posture when that list is already a small trusted group. Setting it to `false` asks for a second person: the publish job then fails when it can see that the environment permits self-review, and warns without failing when GitHub does not report the setting. Both postures still require an explicit, attributed approval before anything is uploaded.
