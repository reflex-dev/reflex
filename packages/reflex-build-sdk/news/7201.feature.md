The client reads its URLs from `REFLEX_BUILD_BACKEND_URL` and `REFLEX_BUILD_URL`, falling back to `REFLEX_CLOUD_BACKEND_URL` and `REFLEX_CLOUD_URL`, which `reflex-hosting-cli` reads. Set both names when the SDK and `reflex deploy` should reach the same backend, since the CLI does not read the `REFLEX_BUILD_*` names.
