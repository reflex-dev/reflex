`reflex_build_sdk.triggers` now verifies the platform's Ed25519 (`v1a`) delivery signatures against the public key in `REFLEX_TRIGGER_PUBLIC_KEY`, so an app no longer holds a secret that could sign a delivery. Once a public key is set, HMAC (`v1`) signatures are refused. Install `reflex-build-sdk[triggers]` to get the `cryptography` package it needs. `triggers.public_key(signing_key)` returns the public half of a `whsk_` signing key.
