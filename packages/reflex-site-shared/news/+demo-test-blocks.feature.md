Docs markdown can hold browser tests in `python test` blocks directly below a `python demo`, `demo-only` or `eval` block. Test blocks are not rendered, and `strip_doc_tests` removes them from served markdown. Each demo's rendered component is wrapped by a `display: contents` element whose `data-docs-demo` attribute is the demo's index in `iter_doc_demos` order. A demo block flagged `notest` (e.g. ```` ```python eval notest ````) is deliberately untested.
