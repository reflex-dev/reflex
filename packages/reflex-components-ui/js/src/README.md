# reflex-ui

The javascript `rx.ui` components are compiled against. Reflex copies this
directory into an app's `.web/reflex-ui/` from the `reflex-components-ui`
package, so an edit made here in an app is overwritten.

The source, its tests and its rules live in
[`packages/reflex-components-ui/js`](https://github.com/reflex-dev/reflex/tree/main/packages/reflex-components-ui/js).
