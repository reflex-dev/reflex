`rx.plugins.UIPlugin(theme=rx.ui.Theme(accent_color="indigo", radius="large"))` themes the whole app, `rx.ui.theme(...)` themes part of a page with the same options, and `rx.ui.tokens` names the design tokens as style values, such as `rx.ui.tokens.space[4]` and `rx.ui.tokens.accent.contrast`. The tokens have the values of Radix Themes.
