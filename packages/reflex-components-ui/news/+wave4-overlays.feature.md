Add the overlays and the disclosure components to `rx.ui`: `tabs`, `accordion`, `dialog` and `alert_dialog`, with the members of each namespace. Each takes the arguments of the component of the same name in `rx` and looks the same. Tabs are buttons and panels the server renders in the state they start in; a small script selects a tab on a press, on the focus and with the arrow keys. An item of an accordion is a native `details`, so it opens and closes before JavaScript loads. A dialog and an alert dialog are a native modal `dialog`: the browser puts it over the page, makes the page behind it inert, moves the focus in and gives it back, and what the dialog holds is in the page the server sends.

A button whose popup is open has the look Radix Themes gives it (`[data-state='open']`), which `rx.ui.button` did not have.
