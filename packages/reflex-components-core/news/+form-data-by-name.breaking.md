Form `on_submit` now builds `form_data` only from each control's `name`, as deprecated in 0.10.1: a control's `id` no longer adds a field, and no longer replaces the value submitted under a `name` equal to it. Give every submitted control a `name`, e.g. `rx.input(id="email")` becomes `rx.input(id="email", name="email")`. Compiling a form whose submit handler takes the form data still warns about each value-bearing control that has a static `id` but no `name`.
