Fixed `rx.form`/`Form` submit handlers silently collapsing a checkbox group or any other multi-value field down to its last checked value. The submit hook built `form_data` with `Object.fromEntries(new FormData($form).entries())`, and native `FormData.entries()` yields one `[key, value]` pair per repeated `name`, so `Object.fromEntries` kept only the last pair for that key. Replaced it with a `formDataToObject` helper that groups repeated keys into an array while leaving single-value keys as plain scalars, so a submitted checkbox group (or any control that reuses one `name` across multiple values) now reports every checked value instead of just one.
