# `upgrade` fixtures — install paths, in-place upgrades, CLI lifecycle, third-party packages, events suite

Curated from the 0.9.9a1 … 0.10.0a5 campaigns (mainly `2026-10-08-a5/a5_upgrade_ent/{up,tp,inst}`, `2026-10-07-a3/{a3_upgrade,a3_events_tp}`,
`2026-10-07/{reverify_db_install,upgrade_sweep}`, `2026-10-06/upgrades_{a,b}`, `2026-09-18-v0.9.12a1/up_examples_a`). Only our own drivers,
probes, patches, small apps and config are here; reflex-examples apps and the third-party demo apps are fetched at run time
(`bin/stage.sh`) at pinned commits and patched. Expected results are the a5 pass (reflex 0.10.0a5) unless marked **re-validated on 0.10.0**.

## How to run the whole area (next pass: `new` / `prev` venvs from `prerelease-testing/scripts/bootstrap_envs.sh`)

```bash
export SB=<scratch root> W=$SB/apps/upgrade NEW=new PREV=prev VENV_PREFIX=upgrade
cd $SB && bash <repo>/prerelease-testing/fixtures/upgrade/bin/stage.sh          # copy fixtures to $W, fetch + patch upstream apps
# install paths (no servers)
bash $W/inst/bin/n001.sh; bash $W/inst/bin/dbcli.sh; bash $W/inst/bin/prod_crud.sh; bash $W/inst/bin/f014.sh; bash $W/inst/bin/install_paths.sh
# in-place upgrades PREV -> NEW (one at a time)
bash $W/up/bin/build_base_venvs.sh fd:form-designer gh:github-stats twr:twitter-redis ck:clock tw:twitter
bash $W/up/bin/seq_fd.sh; bash $W/up/bin/seq_gh.sh; bash $W/up/bin/seq_twr.sh; bash $W/up/bin/seq_ck.sh; bash $W/up/bin/seq_tw.sh
for a in counter reflexle lorem-stream local-component quiz snakegame nba upload; do bash $W/up/bin/build_base_venvs.sh $a:$a && bash $W/up/bin/seq_app.sh $a; done
# third party
bash $W/tp/bin/build_venv.sh; $SB/envs/$VENV_PREFIX-tp/bin/python -I $W/tp/probes/import_sweep.py $VENV_PREFIX-tp > $W/tp/logs/import_sweep.json
$SB/envs/$DRIVER/bin/python -I $W/tp/bin/cmp_sweep.py $W/tp/expected/import_sweep.json $W/tp/logs/import_sweep.json
bash $W/tp/bin/seq_tp.sh; bash $W/tp/bin/run_google.sh
# events, lifecycle, guide, smoke
bash $W/events/bin/start.sh $NEW dev new_dev evapp && bash $W/events/bin/wait_up.sh http://localhost:3460/ && bash $W/events/bin/suite.sh new_dev http://localhost:3460 8460; bash $W/events/bin/stop.sh new_dev
bash $W/lifecycle/bin/json_matrix.sh new $NEW INT-group:40 TERM-pid:40 TERM-pid:6 INT-pid:40; bash $W/lifecycle/bin/f007.sh
bash $W/guide/bin/probe.sh; bash $W/guide/bin/seq_guide.sh; bash $W/smoke/bin/seq_smoke.sh
bash $W/bin/ports.sh      # must print "no listeners"; then rm -rf $W/*/apps/*/.web $W/*/run (node_modules)
```
