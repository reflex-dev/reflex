SUMMARY: Most server/network changes behave as their changelog lines say. Lifespan forwarding to FastAPI/Starlette transformers, case-insensitive routes in dev and prod, the pre-connect on_load fix (HYD-06), the `reflex:state-mismatch` event, the `--frontend-only/--backend-only` config ports, the dev blocking monitor, otel trace ids in JSON logs, and the hosting-cli PyYAML exit code all work.   SEVERITY: low
  REGRESSION: no
