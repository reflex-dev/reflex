# Published hosting CLI JSON integration

Run the public installed CLI in the exact published alpha environment, with credential files redirected to a temporary fixture. A Python audit hook permits only loopback socket connections. A real HTTP server supplies complete Build SDK wire responses and records endpoint methods, paths and request bodies.

Exercise history URLs, timestamps and VM names; inspect nested wire aliases; server-selected token names/expiration; secrets JSON and human output with no value disclosure; role permission names/null results; refused responses; invalid token duration; and deploy project validation before app/build requests. The deploy fixture uses an already initialized temporary app and never returns a successful deployment endpoint.
