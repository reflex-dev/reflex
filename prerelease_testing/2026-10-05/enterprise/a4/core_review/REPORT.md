## Description audit and practical boundaries

[Reviewed descriptions](reviewed-descriptions.json), [fail-fast PR7321](pr-7321.json) and [dependency refresh PR7424](pr-7424.json) retain the primary source narratives. #7312 documents descriptor shadowing/internal-map removal and the rolling-worker exception. #7064 describes boot-time differential hydration; its cookie behavior has a separate fresh root-owned a4 control. #7286 explicitly calls its client-State setter fix a stopgap and excludes broader unmount/lifetime behavior. #7369 changes server providers while retaining client behavior. #7123/#7004 describe memo/compiler changes; the original functional checks and fresh enterprise memo renderer/export are useful coverage, without a performance benchmark claim.

#7353 narrows logging of outer type mismatches; its previous inner check was not an enforced authorization validation. #7357/#7358 describe per-stream upload state and tracing lineage, with explicit cancellation/parent-transaction scope limits. #6553 documents removal of duplicate context state and lookup enforcement; #7237 narrows shared fan-out work. Original multi-client observations support those functional paths but are not a complete adversarial security assessment. #7325/#7326 cover download encoding/slicing, #7339 ABC bookkeeping, #7226 Plotly titles, #7227 ID-backed form controls and #7366 Recharts FunctionVar formatters. No scope mismatch here demonstrates a new blocker.

PR6770's historical description emphasizes scalar server defaults, whereas the published alpha changelog and real CLI behavior evaluate callable defaults. The implementation evidence therefore controls the claim; neither description supports distinct per-row UUID backfill semantics. #7424 refreshes frontend/backend versions and adds a datetime compatibility guard. Original successful apps and exact-graph upgrade checks support compatibility within those flows, without a broad browser/library support guarantee.

Adversarial review: **1.** Original core results are reused, with only six module bytes freshly compared here; dependency/runtime differences remain material. **2.** Functional State/shared-client passes cannot certify an auth failure path or revoke the independent security blocker. **3.** The original incomplete stable scale control must be read with the new bounded comparison, without claiming identical limits. **4.** Unmount/lifetime, exact performance, unique per-row migration backfills and production cloud policy remain outside demonstrated coverage. No source fixes, account mutations or external issue activity were performed by this review.
