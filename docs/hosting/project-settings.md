# Project Settings

Open **Settings** in the project sidebar to review the project's identity and administrative controls.

## General information

The General page shows the project name and ID. Use the ID when a CLI command, API request, or support conversation needs to identify the exact project.

Project admins can rename the project from this page.

## Organization

Every project belongs to an organization. Moving a project can change who inherits access and which organization-level settings apply.

Review [Moving Projects & Apps](/docs/ai/organization/moving-projects-and-apps/) before moving a project.

## Delete a project

Deleting a project permanently removes its apps and deployments. Before deleting it:

1. Confirm that you selected the correct project.
2. Preserve any source, deployment information, or configuration you still need.
3. Review the members and teams that will lose access.

Only delete the project when you no longer need any of its resources.
